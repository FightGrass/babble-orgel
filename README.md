# 옹알이 오르골

아기 옹알이 녹음을 소리 조각으로 나누고, 음정을 맞춰 오르골 반주 위에 올려 짧은 곡으로 만드는 웹 앱입니다.
모든 처리는 브라우저 안에서만 이뤄지고, 소리는 어디에도 업로드되지 않습니다.

## 아이폰에서 열기

1. 이 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 지정합니다.
2. 1~2분 뒤 `https://<깃허브아이디>.github.io/<저장소이름>/` 주소가 생깁니다.
3. 아이폰 Safari에서 열고 공유 → **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

## 쓰는 법

1. **소리 담기**: 녹음 버튼으로 바로 녹음하거나(처음 한 번 마이크 허용), 음성 메모 파일을 불러옵니다.
2. **소리 고르기**: 자동으로 잘린 조각을 들어보고, 곡에 쓸 것만 켭니다.
3. **곡 만들기**: 분위기(자장가 / 놀이 / 꿈나라), 조, 음정 보정 정도를 고릅니다.
4. 곡을 끝까지 한 번 재생한 뒤 **파일로 저장**을 누르면 공유 시트에서 저장하거나 보낼 수 있습니다.

소리가 안 들리면 아이폰의 무음 스위치를 확인하세요.

## 구조

외부 라이브러리 없이 `index.html` 한 파일로 되어 있습니다 (Web Audio API, MediaRecorder 사용).
